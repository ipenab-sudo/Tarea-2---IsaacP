# 1. Descripción del proyecto

Este proyecto corresponde a la Tarea 2 del curso Principios de Programación 1.

El trabajo consiste en desarrollar cuatro programas independientes en Python, utilizando estructuras iterativas para resolver diferentes situaciones prácticas. Durante su desarrollo se aplican ciclos `while` y `for`, estructuras condicionales, contadores, acumuladores y validaciones de datos.

Además, se incluyen seis laboratorios guiados realizados durante el curso, junto con la documentación correspondiente para explicar y comprobar el funcionamiento de las soluciones.

# 2. Objetivos

- Aplicar estructuras iterativas para resolver problemas mediante programación.
- Diferenciar el uso de los ciclos `while` y `for`.
- Implementar contadores y acumuladores.
- Validar los datos ingresados por el usuario.
- Utilizar estructuras condicionales para controlar las operaciones.
- Representar algoritmos mediante diagramas de flujo.
- Documentar y comprobar las soluciones mediante casos de prueba.

# 3. Funcionalidades

El proyecto contiene cuatro ejercicios principales:

## Ejercicio 1. Control de temperatura

Simula el calentamiento de una cámara experimental. Solicita la temperatura inicial, la temperatura objetivo y el incremento por ciclo. Utiliza un ciclo `while` para controlar el proceso y mostrar los incrementos hasta alcanzar o superar el objetivo.

## Ejercicio 2. Registro semanal de consumo de agua

Registra el consumo de agua durante siete días consecutivos. Utiliza un ciclo `for` para calcular el consumo total, el promedio diario, el consumo máximo y la cantidad de días que superaron los 150 litros.

## Ejercicio 3. Administración de un estacionamiento privado

Implementa un menú interactivo para administrar un estacionamiento con capacidad de 20 vehículos. Permite registrar ingresos y salidas, consultar la ocupación y revisar la recaudación. Utiliza `while True` y estructuras condicionales para controlar las operaciones.

## Ejercicio 4. Control de abastecimiento de una expedición

Simula el consumo de agua y alimentos durante una expedición. Controla las existencias disponibles, valida los consumos y calcula los recursos restantes, los promedios diarios y las jornadas completadas.

# 4. Laboratorios guiados

Se incluyen seis laboratorios desarrollados durante el curso:

1. Laboratorio 1: Python y operaciones básicas.
2. Laboratorio 2: Condicionales múltiples (`match-case`).

4. Laboratorio 4: Ciclos `while`.
5. Laboratorio 5: Ciclos `for`.

Cada laboratorio se encuentra organizado en su respectiva carpeta y contiene los archivos Python correspondientes.

# 5. Requisitos previos

Para ejecutar los programas se requiere:

- Python 3 instalado.
- Visual Studio Code.
- Una computadora con acceso a una terminal o consola.
- Los archivos del repositorio descargados localmente.

# 6. Instrucciones de ejecución

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Seleccionar el archivo Python que se desea ejecutar.
4. Abrir la terminal integrada.
5. Ejecutar el programa utilizando el siguiente comando:

```bash
python nombre_del_archivo.py
```

En algunos sistemas puede ser necesario utilizar:

```bash
python3 nombre_del_archivo.py
```

Cada ejercicio funciona de manera independiente y solicita los datos necesarios mediante la consola.
